# Как устроено обновление дизайна

Изменения касаются отображения. Проверка CSV, принадлежности станциям,
источников, baseline и MAE осталась в существующих загрузчиках.

## Новые строки Python: чтение сверху вниз

| Выражение | Что делает и зачем |
| --- | --- |
| `from html import escape` | Подключает экранирование текста: название станции не может превратиться в HTML-разметку. |
| `Path(__file__).with_name('style.css')` | Находит файл оформления рядом с app.py, независимо от папки запуска. |
| `.read_text(encoding='utf-8')` | Читает CSS как Unicode-текст. |
| `st.markdown('<style>' + ... + '</style>', unsafe_allow_html=True)` | Применяет наше локальное оформление. HTML разрешён только для контролируемой разметки; динамические названия экранируются. |
| `st.markdown('''...''', unsafe_allow_html=True)` | Выводит статическую шапку и вступительный блок. Тройные кавычки позволяют записать HTML несколькими строками. |
| `div.lab-topline` | Верхняя строка: название проекта и трек. |
| `span.lab-dot` | Маленький цветной знак перед названием. |
| `section.lab-hero` | Вступительный блок с цветным фоном. |
| `div.lab-eyebrow` | Небольшая подпись над главным заголовком. |
| `h1` и `br` | Главный заголовок и перенос строки. |
| `p` | Кратко объясняет, что можно сделать в приложении. |
| `div.lab-tags` и `span.lab-tag` | Три подписи, обозначающие измерения, ML и источники. Это не числовые показатели. |
| `st.subheader('Explore a cooling system')` | Вводит блок выбора системы. |
| `st.columns([2.3, 1.4, 1], vertical_alignment='bottom')` | Создаёт три колонки относительной ширины 2.3:1.4:1 и выравнивает элементы снизу. |
| `site_column.selectbox(...)` | Размещает прежний выбор площадки в первой колонке. Данные и ключ состояния не меняются. |
| `system_column.selectbox(...)` | Размещает выбор системы во второй колонке. |
| `refresh_column.button(..., width='stretch')` | Кнопка обновления занимает ширину третьей колонки. Нажатие перезапускает отображение, но не обучение. |
| `status_label = {...}` | Переводит внутренний статус в понятную английскую подпись. Это статус данных, а не экологической безопасности. |
| `escape(entry['plant_name'])` | Безопасно вставляет название из реестра в заголовок. |
| `escape(str(entry['cooling_id_eia']))` | Превращает ID системы в текст и экранирует его. |
| `status_label.get(...)` | Получает подпись статуса; неизвестный статус отправляет пользователя к источникам. |
| `div.lab-note` | Всегда показывает ограничение: разница температур системы не равна нагреву водоёма. |
| `overview, performance, evidence = st.tabs([...])` | Создаёт три вкладки и сохраняет их контейнеры в переменные. |
| `with overview:` | Следующие элементы отображаются во вкладке истории. |
| `if measurements is not None and not measurements.empty:` | Разрешает график только при наличии успешно проверенных непустых данных. |
| `st.line_chart(..., height=330, color=['#087f8c'])` | Рисует прежние измерения более крупным бирюзовым графиком. Пропуски не заполняются. |
| `months[0]` и `months[-1]` | Показывают фактические начальный и конечный месяцы выбранного набора. |
| `else: st.info(...)` | Вместо пустого или выдуманного графика объясняет отсутствие подтверждённого ряда. |
| `left, right = st.columns(2)` | Делит объяснения о возможностях и ограничениях на две колонки. |
| `with performance:` | Открывает контейнер вкладки сравнения модели. |
| `model_panel(...)` | Вызывает существующую проверку и отображение результатов выбранной системы. Обучение не запускается. |
| `color=[...]` у тестового графика | Назначает разные цвета измерению, двум baseline и модели, сохраняя порядок столбцов. |
| `(results.model_delta_t_c - results.reported_delta_t_c)` | Для каждого тестового месяца вычисляет отклонение модели от измерения. |
| `.abs()` | Превращает отклонения в абсолютные ошибки: −2 и +2 дают 2. |
| `.idxmax()` | Находит месяц с самой большой абсолютной ошибкой. Это разбор ошибки после оценки, не подбор модели. |
| `worst = results.loc[worst_month]` | Берёт строку этого месяца из уже проверенных результатов. |
| `with st.expander('A closer look: largest model error'):` | Прячет подробный пример ошибки под раскрываемый заголовок. |
| `f'{...:.2f}'` | Выводит число с двумя знаками после запятой; исходное значение не изменяется. |
| `with evidence:` | Размещает источники и ограничения в отдельной вкладке. |
| `source_panel(entry)` | Показывает сведения именно выбранной системы. |
| `with st.expander('Technical provenance'):` | Убирает пути, внутренние статусы и хеши во вложенный блок. Источники и ограничения доступны отдельно. |
| `div.lab-footer` | Добавляет нижнюю подпись проекта, данные EIA/PUDL и напоминание об ограничении. |

Все строки продолжения `f'...'` соединяются Python в один текст.
Строки с закрывающими HTML-тегами завершают соответствующий блок;
отступы после `with` и `if` задают принадлежность инструкций блоку.

## CSS: оформление без изменения вычислений

Каждое правило состоит из селектора и свойств в `{ }`.
`/* ... */` — комментарий, не выполняемый браузером.

| Правило | Объяснение свойств |
| --- | --- |
| `:root` | Переменные `--lab-...` хранят общие цвета. `var(...)` подставляет их в следующие правила. |
| `.stApp`, `stHeader` | `background` задаёт фон, `color` — цвет текста. |
| `.block-container` | `max-width` ограничивает ширину чтения; `padding` оставляет пространство у краёв. |
| `h1, h2, h3` | `letter-spacing` делает заголовки плотнее; `font-size` задаёт размер. |
| `clamp(2rem, 4vw, 3.35rem)` | Главный заголовок меняется с шириной окна, оставаясь между минимальным и максимальным размерами. |
| `line-height` | Расстояние между строками. |
| `.lab-topline` | `display:flex` располагает элементы рядом; `justify-content:space-between` разносит их к краям; `gap` оставляет промежуток. |
| `.lab-brand`, `.lab-eyebrow` | `font-weight` задаёт насыщенность; `text-transform` делает подпись прописной. |
| `.lab-dot` | `width/height` задают размер; `border-radius:50%` превращает квадрат в круг. |
| `.lab-hero` | `linear-gradient` создаёт плавный переход фона; `border` рисует рамку; `border-radius` скругляет углы. |
| `.lab-tags` | `flex-wrap` переносит подписи при нехватке ширины. |
| `.lab-tag` | Рамка, полупрозрачный фон и внутренние отступы формируют небольшую плашку. |
| `.lab-context` | Оформляет название выбранной станции и подпись системы. |
| `stMetric` | Белый фон, рамка, скругление, отступы и слабая `box-shadow` превращают штатные метрики Streamlit в карточки. |
| `stMetricLabel/Value` | Подпись приглушена, значение крупнее и контрастнее. |
| `stSelectbox` | Меняет рамку и скругление штатного списка, сохраняя его поведение и доступность. |
| `.stButton button:hover` | Меняет цвет рамки и текста при наведении. |
| `tab-list`, `tab`, `tab-highlight` | Управляют интервалами вкладок и цветом активного подчёркивания. |
| `[aria-selected="true"]` | Выбирает активную вкладку по её состоянию. |
| `stExpander`, `stAlert` | Скругляют штатные раскрываемые блоки и сообщения. |
| `.lab-note` | Контрастная боковая линия выделяет важное ограничение. |
| `.lab-footer` | Верхняя рамка и маленький шрифт отделяют подпись от основного содержимого. |
| `@media (max-width:640px)` | На узком экране уменьшает отступы и промежутки; это правило адаптивности, а не отдельная версия сайта. |

`rem` зависит от базового размера шрифта, `px` — пиксели, `vw` — доля
ширины окна. CSS использует DOM-селекторы Streamlit: после обновления
Streamlit их внешний вид нужно проверить. Версия зависимости не менялась.
