# Построчный разбор модуля экологических отчётов

Это правила формирования доказательного текста, **не** обученная модель экологической безопасности. Код не меняет Ridge, UI, CSV, Parquet или результаты. Одна реализация обслуживает разные plant_id; неподготовленная станция получает корректный отказ.

Сначала прочитайте CAPABILITY_AUDIT_RU.md: что фактически подтверждают источники, что отсутствует и кому нужна экспертная оценка. source_catalog.json хранит роли/даты; claims.json — тексты/типы/периоды/места поддержки; technical_values.json — отдельные числа; review_index.json — версию проверенной курации, не доказательство истинности.

Ниже каждая непустая физическая строка нового production-кода и тестов приведена дословно, блоками до восьми строк. Пустые строки только отделяют блоки. Многострочные словари/условия поясняются как продолжение указанной операции.
