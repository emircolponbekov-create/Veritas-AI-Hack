# Final submission checklist

Official [Project Briefs](https://drive.google.com/file/d/15tYD48XRmCgWbk1_lLDtc8lebi6qm-4-/view), sections 2, 3 and 5.

- Confirm both participants' real names and actual contributions in PROJECT_SUMMARY.md and CREDITS.md. Enter each participant's name, email and school in the official form; emails and schools do not need to be public here.
- Both participants should understand the method and confirm that their project work was done during the hackathon. Repository timestamps alone do not prove this.
- Run the README installation command, then `python submission/verify_distribution.py --results` using that environment. Do not retrain models or regenerate manifests to hide an integrity error.
- Rehearse the app: Surry CW1 report and source disclosures; a missing/excluded month; Calvert Cliffs; Surry CW2; a second site; and a narrow window. Distinguish saved ML estimates from reported measurements and source-based ecological reports.
- Use the repository URL for code. For the required write-up, the form explicitly accepts a GitHub README, an accessible Google Doc, or a PDF/Word upload. The repository README contains the project overview and results; the detailed write-up is linked from it.
- Open both submitted links in an incognito/private window without signing in. Localhost is not a public demo link. An independently hosted app is not required by the brief.
- List every dataset, model, tutorial and AI tool actually used. Keep the existing credits and add any additional tools, including any used for a video.
- Optional: upload a video of at most two minutes to unlisted YouTube or viewable Google Drive. The video is recommended, not mandatory.
- One teammate submits for the whole team under **AI + Climate**. Save the confirmation. Uploading code to GitHub does not submit the competition form.

Deadline: **15 November 2026, 23:59 ET**, equivalent to **16 November, 07:59 in Antalya (UTC+3)**. The last submission before the deadline is evaluated.
