# Current interface and local release scope

## What visitors can explore

- **Surry:** a partial-evidence site report with mixed historical periods and
  exact claim-to-source disclosures. CW1 water findings are omitted for CW2.
- **Calvert Cliffs:** the real insufficient-evidence publication, alongside its
  own valid measurements and saved model. Insufficient evidence is not safety.
- **Other registered sites:** honest report absence and separately checked
  measurement/model availability. Brunswick has separate systems 1 and 2.
- **Follow a drop:** three selectable educational cooling stages, reviewed
  descriptions/sources and a conditional recirculation loop where applicable.
- **A ribbon of months:** one 2010–2025 control with °C measurements, explicit
  excluded/missing/review states, no interpolation and no fabricated numbers.
- **Why this conclusion?:** the exact reviewed statement, observation period,
  source role/link/locator, geographic scope, limitations and review boundaries.
- **Explore the details:** existing measured history, saved Ridge/baseline
  comparisons, errors, provenance and explicit-input sensitivity scenarios.

The ocean artwork remains illustrative. Decorative motion can be reduced by
an explicit switch and respects OS preferences. Navigation targets exist for
unavailable states; captions, keyboard focus and touch targets are strengthened.

## Methods and limits

Ridge estimates completed-month cooling-system ΔT, not a future forecast.
Environmental reports use curated sources and rules, not a trained safety
model. The report does not update when the historical month changes. No score,
proof of harm/safety, plume map, dose assessment or transfer to Akkuyu is added.
Specialist ecological/health review remains not performed. Scenarios are
hypothetical, not station measurements; uranium mining/milling is still blocked
without verified coefficients. No source/model/evidence publication is changed.

## Package and verification

Current archive: `nuclear-water-release-20261115-interactive.zip`.
The previous `nuclear-water-release.zip` remains unchanged. The explicit-file
packager includes UI modules/CSS/JS/artwork, MODEL support/evidence/publications,
registered observations/saved results, scenario modules, tests and dependencies.
It excludes environments, caches, logs, credentials and ZIP members. It checks
CRC, exact member set and member SHA-256/byte counts. The sibling .sha256 file
checks the outer ZIP. Runtime setup is in ../src/ui/README.md; no training is
needed. See PACKAGE_CHECKS.json for actual checks, including unavailable ones.

The implementation pass observed desktop and 390 px rendering; the finishing
retry could not reconnect the browser or confirm a normal server because of
restricted local sockets. AppTest does not verify CSS/JavaScript/rendering.
Fresh dependency installation and a fully fresh-machine run were not tested.
